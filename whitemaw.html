Project Overview

Development Context

White Maw is a first-person survival horror game where players play as a camper left alone in the snowy Yukon wilderness. Players must survive the night by managing a campfire to keep warm and scavanging for food left by other campers, all while staying quiet to not attract the creature.

My Contributions

  • Designed a dynamic behavior tree for the creature that adapts to the noises that players make when moving and interacting with objects.
  • Implemented sound management system which keeps track of the player's noise levels and updates the creature's behaviors accordingly
  • Implemented audio management system which properly plays audio sfx at appropriate times
  • Implemented the campfire and player heat system interactions

Systems & Implementation

Sound Management

The different tasks that players do generate different noise levels, which are tracked and decayed over time, and change the yeti's behaviours. These levels are tracked within a SoundManager script, which broadcasts the changes to the creature's behavior tree and updates its current state.


In SoundManager.cs
public void AddNoise(float amount)
    {
        currentNoiseLevel = Mathf.Min(maxNoiseLevel, currentNoiseLevel + amount);
        OnNoiseLevelChanged?.Invoke(currentNoiseLevel);
        previousNoiseLevel = currentNoiseLevel;
        //Debug.Log($"Noise increased by {amount}. Current level: {currentNoiseLevel}");
    }

Yeti Behavior

The yeti's behavior is made up of 6 different states:


Patrolling

The yeti's initial state where it simply moves around the campsite in a circular path.


In YetiAI.cs
void PatrolBehavior()
    {
        if (yetiModel.activeSelf)
        {
            yetiModel.SetActive(false);
        }
        // Check if reached current patrol point
        if (!agent.pathPending && agent.remainingDistance <= pointReachedDistance)
        {
            // Move to next random point on circle
            currentAngle += Random.Range(15f, 30f);
            if (currentAngle >= 360f) currentAngle -= 360f;
            SetDestinationToAngle(currentAngle);
        }

        // Only play sound if cooldown is complete
        if (patrolSoundTimer <= 0f)
        {
            PlayMovmentInWoodsSFX();
            patrolSoundCooldown = Random.Range(15, 30);
            patrolSoundTimer = patrolSoundCooldown; // Reset cooldown
        }
    }

Investigating

When the player's noise level reaches 30, the yeti transitions to the investigation state. In this state, the yeti will move to the point on the circular path closest to the player and perform an investigation. If the player is close to the yeti and making noise, the yeti transitions to the stalking state. If not, the yeti has a .1% chance every frame to transition back to patrolling, or it will stay at it's current position and keep looking at the player.


In YetiAI.cs
void InvestigateBehavior()
    {
        if (yetiModel.activeSelf)
        {
            yetiModel.SetActive(false);
        }
        agent.speed = patrolSpeed;

        // Calculate target angle (closest point on circle to player)
        investigationTargetAngle = GetAngleToPlayer();

        // Calculate the shortest angular distance and direction
        float angleDiff = Mathf.DeltaAngle(currentAngle, investigationTargetAngle);
        float absAngleDiff = Mathf.Abs(angleDiff);

        // If close to target angle, start investigation
        if (absAngleDiff <= 2f) // Within 2 degrees
        {
            // Reached the investigation point
            HandleInvestigationComplete();
            return;
        }

        // Move along circle towards target angle
        float moveDirection = Mathf.Sign(angleDiff);
        float moveAmount = Mathf.Min(angularSpeed * Time.deltaTime, absAngleDiff);

        currentAngle += moveDirection * moveAmount;

        // Normalize angle
        if (currentAngle >= 360f) currentAngle -= 360f;
        if (currentAngle < 0f) currentAngle += 360f;

        // Set new destination along the circle
        SetDestinationToAngle(currentAngle);

        // Only play sound if cooldown is complete
        if (investigateSoundTimer <= 0f)
        {
            PlayBreathingSFX();
            investigateSoundCooldown = Random.Range(10, 15);
            investigateSoundTimer = investigateSoundCooldown; // Reset cooldown
        }
    }

    void HandleInvestigationComplete()
    {
        float distanceToPlayer = Vector3.Distance(transform.position, player.position);
        float currentNoise = SoundManager.Instance != null ? SoundManager.Instance.GetCurrentNoiseLevel() : 0f;

        if (distanceToPlayer <= 15f && currentNoise > noiseThresholdForInvestigation)
        {
            // Stalk when player is close and making noise
            ChangeState(YetiState.Stalking);
        }
        else if (Random.Range(0f, 1f) < 0.001f) // .1% chance each frame to return to patrol every frame
        {
            ChangeState(YetiState.Patrolling);
        }
        else
        {
            // Stay at investigation point and face player
            Vector3 lookDirection = (player.position - transform.position).normalized;
            lookDirection.y = 0;
            if (lookDirection != Vector3.zero)
            {
                transform.rotation = Quaternion.LookRotation(lookDirection);
            }
        }
    }

Stalking

In the stalking state, a timer begins and if the player is still within a certain range of the yeti by the end of this timer, the yeti will transition to the hunting state. If the yeti is out of this range, the yeti will transition back to investigating. In addition to this, if the noise level is above a certain threshold, the yeti will transition to the hunting state regardless of the timer and position of the player.


In YetiAI.cs
void StalkingBehavior()
    {
        if (!yetiModel.activeSelf)
        {
            yetiModel.SetActive(true);
        }
        // Stop moving and track the stalking timer
        agent.isStopped = true;

        // Always face the player during stalking
        Vector3 lookDirection = (player.position - transform.position).normalized;
        lookDirection.y = 0;
        if (lookDirection != Vector3.zero)
        {
            transform.rotation = Quaternion.LookRotation(lookDirection);
        }

        // Update stalking timer
        stalkTimer += Time.deltaTime;

        // Only play sound if cooldown is complete
        if (stalkingSoundTimer <= 0f)
        {
            PlayGrowlSFX();
            stalkingSoundCooldown = Random.Range(8, 12);
            stalkingSoundTimer = stalkingSoundCooldown; // Reset cooldown
        }

        // Check if stalking duration is complete
        if (stalkTimer >= stalkDuration)
        {
            float distanceToPlayer = Vector3.Distance(transform.position, player.position);
            if (distanceToPlayer > 15f)
            {
                // Return to investigation when player gets too far
                ChangeState(YetiState.Investigating);
                return;
            }
            else
            {
                // Attack if player is still close
                ChangeState(YetiState.Hunting);
            }
        }

        float currentNoise = SoundManager.Instance != null ? SoundManager.Instance.GetCurrentNoiseLevel() : 0f;
        if (currentNoise > noiseThresholdForHunt)
        {
            // Attack when over threshold
            ChangeState(YetiState.Hunting);
        }
    }

Hunting

In the hunting state, the yeti will chases the player and the player must reach their tent to escape the yeti. If the player reaches the tent, the yeti transitions to the waiting at tent behavior, where the player must complete a quick time event to successfully escape. If the player fails this quick time event, the yeti will attack and kill the player. If the player doesn't reach the tent, the yeti attacks the player.


In YetiAI.cs
void HuntBehavior()
    {
        if (!yetiModel.activeSelf)
        {
            yetiModel.SetActive(true);
        }
        agent.isStopped = false;
        agent.speed = huntSpeed;

        // Start hunting sounds if not already playing
        if (!isPlayingHuntingSounds)
        {
            StartRunningSound();
        }

        // Directly pursue player (break from circular path)
        NavMeshHit hit;
        if (NavMesh.SamplePosition(player.position, out hit, 10f, NavMesh.AllAreas))
        {
            agent.SetDestination(hit.position);
        }

        // Only play sound if cooldown is complete
        if (huntingSoundTimer <= 0f)
        {
            PlayGrowlSFX();
            huntingSoundCooldown = Random.Range(8, 12);
            huntingSoundTimer = huntingSoundCooldown; // Reset cooldown
        }

        // Check if close enough to attack
        if (Vector3.Distance(transform.position, player.position) <= attackDistance)
        {
            ChangeState(YetiState.Attacking);
        }
    }

Attacking

In the attacking state, the yeti will play an attack animation and kill the player.


In YetiAI.cs
void AttackBehavior()
    {
        if (!yetiModel.activeSelf)
        {
            yetiModel.SetActive(true);
        }

        float distanceToPlayer = Vector3.Distance(transform.position, player.position);

        if (distanceToPlayer > attackDistance)
        {
            agent.isStopped = false;
            agent.SetDestination(player.position);
        }
        else
        {
            agent.isStopped = true;
            if (!hasAttacked)
            {
                hasAttacked = true;
                PlayAttackSFX();
                GameManager.Instance.GameOver("yeti");
            }
        }
    }

Waiting at Tent

In the waiting at tent state, the yeti will wait outside the player's tent until the player completes a quick time event to escape.


In YetiAI.cs
void WaitingAtTentBehavior()
    {
        if (!yetiModel.activeSelf)
        {
            yetiModel.SetActive(true);
        }

        if (!agent.pathPending && agent.remainingDistance <= agent.stoppingDistance + 0.5f)
        {
            agent.isStopped = true;
        }

        Vector3 lookDirection = (player.position - transform.position).normalized;
        lookDirection.y = 0;
        if (lookDirection != Vector3.zero)
        {
            transform.rotation = Quaternion.Lerp(transform.rotation, Quaternion.LookRotation(lookDirection), Time.deltaTime * 2f);
        }

        if (stalkingSoundTimer <= 0f)
        {
            PlayGrowlSFX();
            stalkingSoundCooldown = Random.Range(5, 10);
            stalkingSoundTimer = stalkingSoundCooldown;
        }
    }
