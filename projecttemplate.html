Project Overview

Game Overview

Cyber Runner is set in the year 2077 in the megacity of Neo-Kyoto. Players take on the role of Kaito, a freelance "data runner" who specializes in infiltrating high-security corporate facilities to steal valuable information. The game combines fluid parkour movement with stealth and combat elements in a richly detailed cyberpunk world.

The core gameplay loop revolves around planning routes through complex environments, using advanced movement abilities to avoid detection, and extracting sensitive data while evading or confronting corporate security forces.

Development Context

This project was developed as a commercial title by Neon Nexus Studios over an 18-month production cycle. The team consisted of 12 developers with backgrounds in both indie and AAA game development.

We faced significant technical challenges in creating a movement system that felt both realistic and empowering, while maintaining performance across multiple target platforms. The project was built using Unity with a custom rendering pipeline to achieve the distinctive neon-drenched visual style.

My Contributions

As Lead Gameplay Programmer, I was responsible for architecting and implementing the core gameplay systems:

  • Designed and implemented the advanced parkour movement system, including wall-running, sliding, and precision jumping mechanics
  • Created the character controller with responsive input handling and physics-based movement
  • Developed the dynamic camera system that adapts to player movement and environmental context
  • Implemented the AI behavior trees for enemy security forces, including patrol, pursuit, and combat behaviors
  • Built the tools and systems for level designers to create and test parkour routes efficiently
  • Optimized performance across all target platforms, maintaining 60fps on consoles
  • Mentored junior programmers and established coding standards for the team

Technical Challenges

The most significant technical challenge was creating a movement system that felt responsive and fluid while handling complex environmental interactions. I developed a custom collision detection system that could accurately predict movement trajectories and handle edge cases like cornering and complex geometry.

Another major challenge was optimizing the visual effects and post-processing needed for our distinctive cyberpunk aesthetic without compromising performance on console hardware.
