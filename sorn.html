Project Overview

Development Context

S.O.R.N. is a third-person action mech shooter developed by a team of 15 students at UCF over the course of an academic year. The game is built in Unreal Engine 5 and features a variety of gameplay pillars including mech combat and customizaion, narrative exploration, and AI-driven enemy encounters.


The game features a complex combat and upgrade system using Unreal's Gameplay Ability System. Players can customize their mech with different weapons, abilities, and loadouts to suit their playstyle. It also features cooperative multiplayer, allowing players to team up together against challenging AI enemies and bosses.

My Contributions

  • Implemented a complex customization system for mechs using Unreal's Gameplay Ability System which allows players to modify their mech's parts and weapons.

Systems & Implementation

Mech Part Switching

Player mechs are highly customizable with different parts including arms, legs, and torsos. Each part provides different stats which are then applied to the player using Unreal's Gameplay Ability System. The system uses data assets for each part which holds the gameplay effect to be applied to the player, as well as the corresponding skeletal meshes and effects.

void AMechCharacter::HandleMechPartGameplayEffect(EMechBodyPart MechPart, UDA_MechPartData* PartData)
{
	// Removes current effect for part if it exists
	if (ActivePartEffectHandles.Contains(MechPart))
	{
		FActiveGameplayEffectHandle Handle = ActivePartEffectHandles[MechPart];

		if (Handle.IsValid())
		{
			SORNAbilitySystemComponent->RemoveActiveGameplayEffect(Handle);
		}

		ActivePartEffectHandles.Remove(MechPart);
	}

	// Apply the new gameplay effect
	if (PartData && PartData->GameplayEffect)
	{
		FActiveGameplayEffectHandle NewHandle = SORNAbilitySystemComponent->ApplyGameplayEffectByClass(PartData->GameplayEffect);

		if (NewHandle.IsValid())
		{
			ActivePartEffectHandles.Add(MechPart, NewHandle);
		}
	}
}

void AMechCharacter::UpdateMechPartVisuals(EMechBodyPart MechPart, UDA_MechPartData* PartData)
{
	// Update part data reference
	switch (MechPart)
	{
	case EMechBodyPart::EMBP_Legs:
		{
			LegsPartData = PartData;
			GetMesh()->SetSkeletalMesh(LegsPartData->Mesh);
			GetMesh()->SetAnimInstanceClass(LegsPartData->AnimBP);
			AttachEngineEffectsToSockets(GetMesh(), LegsPartData->EngineAttachPoints, LegsPartData->EngineEffect);
			break;
		}
	case EMechBodyPart::EMBP_UpperBody:
		{
			UpperBodyData = PartData;
			UpperBodyMeshComponent->SetSkeletalMesh(UpperBodyData->Mesh);
			UpperBodyMeshComponent->SetAnimInstanceClass(UpperBodyData->AnimBP);
			AttachEngineEffectsToSockets(UpperBodyMeshComponent, UpperBodyData->EngineAttachPoints, UpperBodyData->EngineEffect);
			break;
		}
	case EMechBodyPart::EMBP_LeftArm:
		{
			LeftArmPartData = PartData;
			LeftArmMeshComponent->SetSkeletalMesh(LeftArmPartData->Mesh);
			LeftArmMeshComponent->SetAnimInstanceClass(LeftArmPartData->AnimBP);
			AttachEngineEffectsToSockets(LeftArmMeshComponent, LeftArmPartData->EngineAttachPoints, LeftArmPartData->EngineEffect);
			break;
		}
	case EMechBodyPart::EMBP_RightArm:
		{
			RightArmPartData = PartData;
			RightArmMeshComponent->SetSkeletalMesh(RightArmPartData->Mesh);
			RightArmMeshComponent->SetAnimInstanceClass(RightArmPartData->AnimBP);
			AttachEngineEffectsToSockets(RightArmMeshComponent, RightArmPartData->EngineAttachPoints, RightArmPartData->EngineEffect);
			break;
		}
	default:
		return;
	}
}

Color Customization

In addition to part switching, players can also customize the colors of their mech. There is a master material which has parameters for a texture mask, a primary color, and a secondary color. There is then a series of lerp and multiply nodes which blend the colors based on the texture mask. Players can select their colors using a color picker UI, and the selected colors are then applied to the material parameters using a dynamic material instance.

Weapons

Mechs can equip different weapons on their arms which are then used in combat. Each weapon has its own unique behavior and properties, and they are implemented using Unreal's Gameplay Ability System. There is a base weapon class which is used for standard weapons, such as the minigun and shotgun. A charged weapon class inherits this class and is used for the railgun and charge pistol. The final weapon class is the beam weapon which shoots a laset that deals consistent tick damage.
