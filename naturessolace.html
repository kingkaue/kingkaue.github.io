Project Overview

Development Context

Nature's Solace is a 3D narrative-based RPG where players play as Micah, a man who is greiving over the loss of his wife. Players must fill their "spirit meter" by interacting with different parts of nature, such as picking flowers, feeding deer, and catching butterflies.


This project was submitted as an entry to the 2025 Games for Change competition.

My Contributions

  • Implemented character controls such as walking and interactions using Unity’s New Input System
  • Implemented setting controls which allow for changing volume and camera sensitivity
  • Implemented a grayscale system using Unity's cinemachine that increases the saturation on the player camera when the player completes tasks
  • Created a scene loading system between four levels using additive loading for retaining the status of the hub level
  • Implemented an inventory system which keeps track of items picked up at different levels that are accessed in the hub level

Systems & Implementation

Color Shift

The system uses a script called CameraGrayscaleShift which checks the player's spirit meter values and adjusts the camera saturation accordingly. When players complete tasks, the script handling the task calls a function in the PlayerManager script that increases the spirit meter.


In CameraGrayscaleShift.cs
void Update()
{
  if (playerManager != null && ca != null)
    {
        float spiritPercent = playerManager.GetSpirit() / playerManager.GetMaxSpirit();
        ca.saturation.value = Mathf.Lerp(-100, 0f, spiritPercent);
    }
}

In PlayerManager.cs
public void SetSpirit(float spiritChange)
{
    spirit += spiritChange;
    spirit = Mathf.Clamp(spirit, 0, maxSpirit);

    spiritBar.SetSpirit(spirit);
}

public float GetSpirit()
{
    return spirit;
}
Async Scene Loading

Because the game has a hub level and three different levels that players can enter, we implemented an async scene loading system that allows players to load in and out of levels without losing the status of the hub level. This was done using Unity's SceneManager.LoadSceneAsync function with additive loading.


In AsyncLoader.cs
public IEnumerator LoadLevelASync(string levelToLoad)
    {
        // Reset slider
        loadingSlider.value = 0f;

        AsyncOperation loadOperation = SceneManager.LoadSceneAsync(levelToLoad);
        loadOperation.allowSceneActivation = false;

        while (!loadOperation.isDone)
        {
            float progressValue = Mathf.Clamp01(loadOperation.progress / 0.9f);
            loadingSlider.value = progressValue;

            if (progressValue >= 0.9f)
            {
                // Wait one extra frame to ensure everything is loaded
                yield return null;

                loadOperation.allowSceneActivation = true;
            }

            yield return null;
        }

        // Additional wait to ensure new scene is fully loaded
        yield return null;

        // Disable loading screen
        if (loadingscreen != null)
        {
            loadingscreen.SetActive(false);
        }

        // Destroy this object if marked to do so
        if (destroyOnLoad)
        {
            Destroy(this.gameObject);
        }
    }
